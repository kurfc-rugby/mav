# KURFC マルチアングル

鹿児島大学ラグビー部（KURFC）の試合動画を、最大6アングルまで同期して並べて見るためのビューアです。

**使う：** https://kurfc-rugby.github.io/mav/

- 各枠に「PCやスマホの動画ファイル」か「YouTubeのURL」を入れる
- `1`〜`6` でメインのアングルを切り替え、「大＋小／均等／自由」で並べ方を変更（自由ではドラッグで移動・角で大きさ変更）
- 通信が重いときは「軽量」（メインだけ再生）
- 「同期を合わせる」で各カメラの録画開始のズレを揃える
- トライ・スクラムなどのタグを付けて、一覧から頭出し・タグの場面だけ連続再生
- 「共有リンクをコピー」で、YouTubeの動画・ズレ・タグをそのまま部員に送れる

動画はどこにもアップロードされません（ファイルはその端末の中で再生、YouTubeは埋め込みで再生）。
同期のズレやタグは、使っているブラウザの中にだけ保存されます。

## 短縮リンク

共有リンクは `https://kurfc-rugby.github.io/mav/?openExternalBrowser=1#k=Ab3x9Q` のように短くなります。
中身（YouTubeのID・ズレ・タグ）は部のGoogleアカウントのスプレッドシートに保存され、`gas/Code.gs`（Google Apps Script）が保存と取り出しをします。
短縮できないとき（電波が悪い等）は、今までどおり中身を全部含んだ長いリンクになります。

## みんなのメモ

短縮リンク（`#k=…`）で開いた画面では、開いた人が誰でも「みんなのメモ」を名前付きで書き込めます（タグへの返信も可）。
メモは同じリンクを開いた全員に約30秒以内で表示され、自分が書いたメモだけ消せます。
同じ分析から作り直したリンク（タグを足して共有し直した等）は同じメモ帳を使うので、前のリンクに書かれたメモも見えます。
